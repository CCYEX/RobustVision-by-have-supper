# 指标词典（大白话 + 术语双解释）

本项目所有 md 文件里出现过的指标，一次讲清。每条先说人话，再给严谨定义，最后配本项目的真实数字。
面试前把这一篇过一遍，任何指标都能接得住。

## 一、检测效果类（"找得准不准"）

### GT（Ground Truth，真值/标注）
- **大白话**：人工事先标好的正确答案——图里有哪些目标、框在哪儿。考试的标准答案卷。
- **术语**：数据集中人工标注的目标边界框与类别，作为评测的参照标准。
- **本项目**：BDD100K 的 box2d 标注，筛出 10 类驾驶目标（labels10 口径）。

### IoU（Intersection over Union，交并比）
- **大白话**：衡量你画的框和标准答案框的重合程度——两个框的"交集面积 ÷ 并集面积"。完全重合 = 1，完全不沾边 = 0。一般 ≥0.5 算"找对了"。
- **术语**：预测框与真值框交集与并集面积之比，取值 [0,1]，是判定 TP 的阈值标准。
- **本项目**：评测匹配阈值 0.5；mAP50-95 则在 0.5~0.95 共 10 档阈值下综合计算。

### 置信度（confidence，conf）
- **大白话**：模型每画一个框时自报的"我有多确定这是对的"，0~1 的小数。0.9 = 很确定，0.3 = 它自己也没底。
- **术语**：检测头输出的该框含目标且类别正确的概率估计（经 sigmoid 归一化的分数）。
- **本项目**：评测时全部保留（不过滤），缓存进 parquet 后再按条件/阈值分析。

### TP / FP / FN
- **大白话**：找对了（True Positive）、找错了/多报了（False Positive）、漏了（False Negative）。报假警和漏报是两种不同的错。
- **术语**：按 IoU 阈值与类别匹配判定；一个真值只能被"认领"一次（贪心匹配），重复认领的算 FP。

### P（Precision，查准率/精确率）
- **大白话**：模型报出来的框里，有多少是真的。**"报得准不准"**——抓错人冤枉好人的比例。
- **术语**：P = TP / (TP + FP)。
- **本项目**：M0 在 clean_day 上 P=0.7137，即每报 100 个框约 71 个是对的。

### R（Recall，查全率/召回率）
- **大白话**：实际存在的目标里，模型找到了多少。**"漏没漏"**——放跑真凶的比例。
- **术语**：R = TP / (TP + FN)。
- **本项目**：M0 在 clean_day 上 R=0.484，即 100 个真目标约漏掉 52 个（检测任务召回天然偏低，因为小目标和遮挡多）。

### PR 曲线（Precision-Recall Curve）
- **大白话**：把置信度门槛从 1 慢慢降到 0，每个门槛下算一次 P 和 R，连成的曲线。门槛高 → 报得少但准（P 高 R 低）；门槛低 → 报得多但杂（R 高 P 低）。曲线越鼓（越靠右上角）越好。
- **术语**：以置信度为扫描变量的 P-R 权衡曲线，曲线下面积即 AP。

### AP（Average Precision，单类平均精度）
- **大白话**：某一类目标（比如"car"）的 PR 曲线下面积，综合了查准和查全，一个数说好坏。
- **术语**：单一类别在所有召回水平上的精度积分（实践中按置信度排序逐点累加）。
- **本项目**：per-class AP 见 `results/m*_full_perclass.csv`；motor 是全条件掉分最狠的类。

### mAP50（mean Average Precision @ IoU 0.5）
- **大白话**：框只要和答案重合一半以上（IoU≥0.5）就算对，在这个"宽松判卷标准"下，所有类别 AP 的平均值。
- **术语**：IoU 阈值取 0.5 时的类平均 AP。
- **本项目**：M0 clean_day mAP50 = 0.5248。

### mAP50-95（= 表里的 mAP / map，主指标）
- **大白话**：把判卷标准从"重合一半就算对"逐级收紧到"重合 95% 才算对"（0.5, 0.55, …, 0.95 共 10 档），每档各算一个 mAP 再平均。**框画得糙不糙也计入成绩**，所以比 mAP50 严格得多、数值也低得多。这是整个项目的主指标。
- **术语**：COCO 标准 10 档 IoU 阈值下的平均 mAP。
- **本项目**：M0 clean_day 0.3022、night 0.2231；M2 night 0.2546。全部阶梯表数字都是它。

### 分数换算（0.30 = "30 分"）
- 口语里说"掉了 3 分" = mAP 绝对值变化 0.03；"掉 30%" = 相对变化 30%（rel_drop，见下）。本项目文档里"分"一律指前者（绝对 0.01 = 1 分），"%"指后者。

### 混淆矩阵（Confusion Matrix）
- **大白话**：一张"对答案"表格——每行是真类别，每列是模型判的类别，对角线上的数字越多越准。能看出模型把"rider"认成"person"这类具体错误。
- **术语**：类别 × 类别的判定计数矩阵（含背景 FN/FP 行列）。
- **本项目**：`results/training/m*_confusion_matrix.png`（三模型各一张，Ultralytics 训练时自动产出）。

## 二、置信度校准类（"它自己说的把握，可信吗"）

检测分数回答"找得准不准"；校准回答另一个正交问题：**模型自报的置信度是不是诚实的**。

### 置信度校准（Calibration）
- **大白话**：模型说"我 80% 确定"的那批预测，实际是不是真有 8 成是对的？是 → 校准好（诚实）；实际只有 6 成 → 过度自信（吹牛）；实际有 9 成 → 不够自信（保守）。**模型可以检测很强但校准很差，两者互不影响**——所以校准要单独测。
- **术语**：预测置信度与经验正确频率的一致程度。

### 匹配打标签（校准的前置步骤）
- **大白话**：把每个检测框和真值按 IoU≥0.5 配对（一个真值只能配一次），配上 = 这框"对"（标签 1），配不上 = "错"（标签 0）。于是几十万个检测框变成几十万道"对/错"的判断题，才能统计置信度诚不诚实。
- **术语**：贪心 IoU 匹配（≥0.5，每真值一次）产生 0/1 正确性标签。

### logit
- **大白话**：模型最后一层还没压到 0~1 之间的"原始分数"。温度缩放就在这一层动手脚，所以要先认识它。
- **术语**：sigmoid 逆变换前的实值输出 z，sigmoid(z) ∈ (0,1) 即置信度。

### 温度缩放 / 温度 T（Temperature Scaling）
- **大白话**：给模型的自信装一个"旋钮"。T>1 = 整体调低自信（治吹牛），T<1 = 整体调高自信（治怂）。只动自信度，**不改变谁排前谁排后**，所以检测的 mAP 一个数都不变。T 的值在一小部分数据（校准集）上"试出来"，用到所有数据上。
- **术语**：p' = sigmoid(logit / T)，单参数在留出校准集上以最小化 NLL 求得（bounds 0.05–10，标量优化）。因单调性不变排序，检测指标不变。
- **本项目**：M0 T=0.762（<1 → 原模型偏保守/不够自信，与文献中"网络普遍过自信"相反，是我们实测的诚实发现）；M2 T=0.8076。校准集 2,999 张 clear-day。

### NLL（Negative Log-Likelihood，负对数似然）
- **大白话**：温度 T 的"考卷"。固定一组预测结果，换个 T 就换个总分，哪个 T 总分最低（NLL 最小）就用哪个。数值越小 = 概率预测越贴合实际对错。
- **术语**：-Σ [y·log p + (1-y)·log(1-p)]，二元交叉熵；优化目标。
- **本项目**：M2 校准集 NLL 0.3976 → 0.3912。

### ECE（Expected Calibration Error，期望校准误差，15 桶）
- **大白话**：**校准的主指标**。把所有检测按自信度分进 15 个桶（0~0.1 一桶、0.1~0.2 一桶…），每桶里比一比"平均自信度"和"实际答对率"差多少，再加权平均。0 = 完美诚实。0.08 大概是"说八成把握的，实际只对七成"这种量级的偏差。
- **术语**：15 分桶 |conf − acc| 的样本量加权平均。
- **本项目**：M2 clean_day ECE 0.0842 → 0.0775（校准后相对下降 8.0%）；snow 0.0812 → 0.0658（−19.0%）。

### MCE（Maximum Calibration Error，最大校准误差）
- **大白话**：15 个桶里**最差那一桶**的偏差。ECE 是平均分，MCE 是"最烂的一科"——看模型会不会在某个自信区间突然严重吹牛。
- **术语**：max over buckets |conf − acc|。
- **本项目**：M2 fog MCE 0.496→0.636（样本仅 92 个检测，波动大，报告如实呈现）。

### Brier 分数（Brier Score）
- **大白话**：另一种给"概率预测"打分的方法——每道题按 (自信度 − 对错)² 罚分再平均。比 ECE 更平滑（不依赖分桶方式），两个一起看更稳。
- **术语**：mean[(p − y)²]。
- **本项目**：M2 clean_day 0.1195 → 0.1169（越小越好）。

### 可靠性图（Reliability Diagram）
- **大白话**：ECE 的可视化版。横轴 = 嘴上说的把握，纵轴 = 实际答对率，每个桶一个点。点落在对角虚线上 = 诚实；整体在上方 = 保守（说 0.6 实际对 0.8），在下方 = 吹牛。蓝色实线是校准前，红色虚线是校准后，**红线比蓝线更贴对角线 = 校准有效**。
- **术语**：分桶置信度-经验准确率折线图，附完美校准对角参考线。
- **本项目**：`results/calibration/m*/reliability.png`，每模型一张、7 个条件面板。右下角多余空面板为布局占位。

### 保险丝检查（monotone check）
- **大白话**：改动后抽查确认所有检测的分数大小排序一个都没变——证明"校准只动自信度、不动检测结果"，mAP 前后一致是数学保证而非巧合。
- **术语**：温度缩放为严格单调变换，抽样验证 logit 排序逐位不变。

## 三、项目协议类（我们自己定的口径）

### clean_day（晴天白天，基准条件）
- **大白话**：天气 clear 且 白天 daytime 的测试图，共 1,235 张，是"考场里的正常照明卷"。所有掉分（rel_drop）都以它为 100 分基准。
- **术语**：BDD100K 属性 weather=clear ∧ timeofday=daytime 的测试子集；合成损坏也以它为底图（成对参照）。

### rel_drop（相对掉分）
- **大白话**：某条件下相对 clean_day 掉了百分之几。（该条件 mAP − clean mAP）÷ clean mAP。−34.3% = 掉了三分之一的分数。
- **术语**：相对基准条件的 mAP 变化率（%）。
- **本项目**：M0 最狠三条件：gauss_noise −34.3%、rain_s2 −27.7%、night −26.2%。

### 自然偏移平均 / 合成损坏平均
- **大白话**：把 13 个测试条件分成两组分别算平均分——**自然组**（夜/雨/雪/晨昏，路上真实会遇到的）看真实泛化，**合成组**（7 种人工像素损坏，stress test）看抗干扰极限。分组平均防止"合成条件好练"掩盖"真实条件没进步"。
- **术语**：natural-shift mean（night/rain/snow/dawn_dusk）与 synthetic-corruption mean（7 corruptions @ severity 2）。
- **本项目**：自然组 M0 0.2668 → M2 0.2822（+1.4 分）；合成组 M0 0.2538 → M1 0.2723（M1 主场，+1.9 分）。

### 阶梯差值 Δ（M1−M0、M2−M1）
- **大白话**：三模型阶梯表里每个条件后的差分列。"M1−M0 = 这一步合成增强的净收益"；"M2−M1 = 加真实夜间数据的净收益"。因为三个模型除数据外一切配置相同，差值就是因果归因。
- **术语**：控制变量设计下的逐级差分（数据是唯一变量：seed/架构/超参/起点权重全同）。

### severity 2（文件名里的 `_s2`）
- **大白话**：合成损坏的"用力程度"分 0~5 档，我们统一用第 2 档——中等强度，模拟真实传感器退化，不至于把图毁得连人都看不出来的程度。
- **术语**：corruption severity level 2（COCO-C/imagenet-c 惯例的 5 级标度）。

### 其他(undefined)（校准报告里的兜底桶）
- **大白话**：BDD100K 里一部分图天气/时段属性缺失或写不出名字，单独归成一桶统计，**不混进任何命名条件里充数**，保证 6 个命名条件的口径纯净。
- **术语**：attributes 缺失/未定义样本的 fallback 桶（fillna 处理）。

### labels10 口径
- **大白话**：只考 10 类驾驶目标（person…traffic sign），BDD 标注里其他任务的面条线（车道线等）不参与计分。
- **术语**：按 10 类白名单过滤 box2d 标注的评测口径。

### fog 仅 9 张（样本量警示）
- 自然雾测试图只有 9 张，雾的结论主要看合成雾（fog_s2，1,235 张）。表中直接标注提醒读者，不装作很确定。

## 四、训练过程类（训练日志/曲线图里的词）

### epoch（轮）
- **大白话**：把训练集完整过一遍叫一轮。M0/M1 各 40 轮上限，M2 30 轮。
- **术语**：一次完整训练集迭代。

### patience = 15（早停耐心）
- **大白话**：连续 15 轮验证分数不再进步就自动停，防止空烧显卡。
- **术语**：early-stopping 容忍轮数。

### batch = 8（批大小）
- **大白话**：每次一起塞给显卡 8 张图算梯度。8GB 显存的安全值，三个模型统一用 8 保证可比。
- **术语**：每步前向/反向的样本数（8GB VRAM 约束下的选定值）。

### AMP（混合精度）
- **大白话**：让显卡一半时间用"半精度小数"算数，省显存又提速，精度几乎不损。
- **术语**：FP16/FP32 自动混合精度训练。

### it/s（张/秒）
- **大白话**：训练速度——每秒处理几张图。本机 4060 约 5.5 张/秒，一轮 1.1 万图约 35 分钟。
- **术语**：images per second 吞吐。

### seed = 42（随机种子）
- **大白话**：固定所有随机性（数据打乱、初始化）的"抽签号码"，让任何人重跑都拿到一样的结果。
- **术语**：全局随机种子，控制数据抽样与训练随机过程。

### box_loss / cls_loss / dfl_loss（三条训练损失曲线）
- **大白话**：训练时模型犯的三类错，各罚一笔分：**box** = 框画歪了罚多少；**cls** = 类别认错了罚多少；**dfl** = 框边缘画得犹豫不决罚多少。三条曲线都应一路下降然后走平。
- **术语**：YOLO11 的回归损失（CIoU）、分类损失（BCE）、分布焦点损失（distribution focal loss，对框边界分布的精细化回归）。

### train / val（训练集 / 验证集）
- **大白话**：train 是练习册（平时做题），val 是模拟考（每轮考一次，用来决定早停和选 best.pt）。**最终成绩另在 test 上另考**，不参与训练。
- **术语**：拟合用子集 / 模型选择与早停监控子集。

### COCO 预训练 + 微调（fine-tune）
- **大白话**：不从零教起——先拿已经在 33 万张通用图上毕了业的模型（yolo11m.pt），再用我们的驾驶数据"进修"。三个模型用同一份起点权重，保证起点公平。
- **术语**：COCO-pretrained YOLO11m 权重迁移学习。

### best.pt / last.pt
- **大白话**：best = 模拟考考得最好那一轮存的档；last = 最后一轮的档（用于断点续训）。**所有评测和发布都用 best.pt**。
- **术语**：按验证 fitness 最优检查点 / 最新检查点。

### params / GFLOPs（模型卡里）
- **大白话**：params = 模型有多少个可调的"旋钮"（YOLO11m 约 2,000 万个）；GFLOPs = 处理一张图要做多少十亿次运算，衡量计算开销。
- **术语**：参数量（M）/ 单前向浮点运算量（10⁹）。

### imgsz = 640
- 输入统一缩放到 640×640 训练与评测（三模型一致）。

## 五、一段话串起来（电梯演讲版）

> 我们用 **mAP50-95**（十档严格判卷的主指标）给三个只差训练数据的模型打分：以 **clean_day** 为基准算 **rel_drop**，发现夜间掉 26%；M1 用合成增强把噪声类掉分从 34% 收到 15%（**阶梯差值 Δ** 归因），但对真实夜间零迁移；M2 加真实夜雨数据把夜间从 0.2231 拉到 0.2546（**自然偏移平均** +1.4 分），代价是 clean −0.6 分。再用 **温度缩放**（T<1，说明模型偏保守）修正置信度——**ECE** 降 8~20% 而 **NLL** 同步下降，**保险丝检查** 证明排序不变所以 mAP 分毫未动；夜间 ECE 本已良好是诚实的负结果。
