# Model Card: M1（合成增强鲁棒版）

## 基本信息

| 项 | 内容 |
| --- | --- |
| 架构 | YOLO11m（与 M0/M2 完全一致，含 batch/seed/imgsz） |
| 训练数据 | M0 的 11,454 张晴天白天 + **3,436 张合成损坏副本**（7 种像素级损坏，标注框不变），共 14,890 张 |
| 训练 | 单张 RTX 4060 Laptop（8GB），40 轮 |
| 角色 | 阶梯第 2 级：回答「合成增强能买回多少鲁棒性、买不到什么」（RQ2） |

## 各条件成绩（mAP50-95，test 侧）

| 条件 | M0 | M1 | 变化 |
| --- | ---: | ---: | ---: |
| 晴天白天 | 0.3022 | 0.3024 | **+0.0002（零代价）** |
| 高斯噪声 s2 | 0.1986 | 0.2567 | **+0.0581（−34.3% → −15.1%）** |
| 合成雨 s2 | 0.2186 | 0.2630 | +0.0444 |
| 合成损坏平均（7 种） | 0.2538 | 0.2723 | **+0.0185** |
| 夜间（真实） | 0.2231 | 0.2206 | **−0.0025（零迁移）** |

## 核心结论（详见 case_study RQ2）

合成增强是**对称解药**：对训练时见过的同类损坏大幅恢复且 clean 零代价；
但**不迁移到真实夜间**——这是 M2 引入真实恶劣条件数据的动机。

## 置信度特性

温度缩放 T = 0.7701（<1：校准前不够自信）；NLL 0.3769 → 0.3673，全条件 ECE 相对下降 10.7~30.4%。

## 适用与不适用

- ✅ 适合：已知损坏类型可控的图像质量退化场景（传感器噪声/压缩/低分辨率）；
- ❌ 不适合：真实昼夜偏移（夜间零提升）；夜景部署请用 M2。

## 局限

损坏仅 severity 2 一档；合成损坏的分布覆盖不了真实光照偏移（这正是本卡片的实证结论）。

## 许可

权重基于 BDD100K（研究用途许可）训练，随本项目 Release 发布，仅供研究用途；不再分发任何训练原图。
