# Case Study: Object Detection Robustness under Real-World Distribution Shifts

**恶劣条件下的目标检测鲁棒性：BDD100K 实证研究**（状态：RQ1/RQ3(M0) 已锁定实测数字；RQ2 待 M1/M2）

## 研究问题

- **RQ1**：各自然/合成偏移条件让检测器损失多少 mAP？失败集中在哪些类别？
- **RQ2**：仅用 clear+daytime 训练时，合成增强能恢复多少偏移条件性能、clean 损失多少？（待 M1/M2）
- **RQ3**：偏移条件下置信度还剩多少可信度？全局温度缩放能修复多少？（M0 已完成）

## 设定

YOLO11m 由 COCO 预训练迁移微调，训练集 = BDD100K train 中「晴天∩白天」的**全部 11,454 张**
（模型从未见过夜间/雨天——分布偏移由此获得干净定义；训练监控留出 1,000 张）。
三个模型（M0 基线 / M1 合成增强 / M2 混合真实恶劣数据）除训练数据外配置完全一致
（imgsz 640、batch 8、AMP、seed 42、patience 15）——每一级增量都可归因。

评测 = 自然条件（test 侧分层子集）+ 7 种合成损坏 × 中档强度（1,235 张与干净参照**同图配对**）。
分层切分、校准集/测试集分离（2,999 / 7,001）、mAP50-95 为主指标。

## 数据审计发现（写在结果前面，因为它们决定了协议）

1. **clear 与 daytime 并不独立**：val 的 clear∩daytime 仅 1,764 张（clear 大部分是夜景、白天大部分是阴天）→ 损坏评测底图改用 test 侧 clean_day 全集 1,235 张，与干净参照同图配对；
2. **train 的 clear∩daytime 仅 12,454 张**（原假设 2 万）→ 训练池改全量使用；
3. **小目标集中度**：traffic light 88.3%、traffic sign 74.9%、person 48.4% 的框是小目标（<32×32 px）——与后面的"哪些类掉分最狠"互相印证。

## RQ1 结果：M0 退化矩阵（test 侧 13 条件，2026-08-30）

M0：clean_day **mAP50-95 = 0.302**（mAP50 0.525）。

| 条件 | mAP50-95 | 相对掉分 |
| --- | ---: | ---: |
| 夜间 | 0.2231 | **−26.2%** |
| 高斯噪声（最狠） | 0.1986 | **−34.3%** |
| 合成雨 | 0.2186 | −27.7% |
| 运动模糊 | 0.2217 | −26.6% |
| 雪 | 0.2542 | −15.9% |
| 自然雾（仅 9 张，参考） | 0.2563 | −15.2% |
| 低光 | 0.2681 | −11.3% |
| 雨 | 0.2750 | −9.0% |
| 低清 | 0.2807 | −7.1% |
| 合成雾 / JPEG | 0.2946 / 0.2942 | −2.5% / −2.6% |
| 晨昏 | 0.3149 | **+4.2%** |

**四个发现**：

1. **夜间 −26.2%** 是自然条件里最大的坑——正是训练分布里被删掉的那一档；
2. **最受伤的类是 motor（平均 −36.0%）**：目标小 + 样本少（train 仅 3,002 框）+ 恶劣条件放大；traffic light/person 次之——与审计"小目标占比"互相印证；
3. **晨昏 +4.2%**（好于 clean_day）：晨昏光比大、轮廓清晰，对检测反而有利——"偏移 ≠ 一定变差"的反例，如实记录；
4. 合成雾/JPEG 几乎不掉分（−2.5%）而合成雨掉 27.7%：像素级"看起来坏"不等于"检测上坏"——损坏类型与检测特征的相关性才是关键（这为"为什么不做去雾前端"提供了数据支撑）。

定性失败案例：`results/qualitative/`（夜间漏检行人 12 张，最多一张漏 6 人、模型最高把握仅 0.157）。

## RQ3 结果：M0 置信度校准（检测版温度缩放，2026-08-30）

方法：检测按置信度贪心匹配（同类、IoU≥0.5、每真值框认领一次）→ 0/1 判卷 →
校准集（2,999 张 clear-day 侧）拟合全局温度 T → test 各条件报告 ECE(15 桶)。
温度缩放是单调变换 → **mAP 逐位不变**（已程序验证）。

**M0：T = 0.762（<1，模型整体略偏"谦虚"——与文献常见的"过自信"相反，本身是个发现）**；
NLL 0.3754 → 0.3650；全局 T 让**所有条件 ECE 下降 12~29%**：

| 条件 | ECE 前 | ECE 后 | 相对下降 |
| --- | ---: | ---: | ---: |
| 雪 | 0.0721 | 0.0516 | **−28.5%** |
| 雨 | 0.0678 | 0.0511 | **−24.7%** |
| 夜间 | 0.0656 | 0.0525 | **−20.0%** |
| 晨昏 | 0.0778 | 0.0682 | −12.4% |
| 晴天白天 | 0.0839 | 0.0710 | −15.4% |

诚实注记：M0 的绝对 ECE 水平不高（0.07~0.13），"夜间过自信"的戏剧性叙事**没有被数据支持**
——夜间在校准前反而是最诚实的条件之一。校准改善真实且全条件一致，但幅度温和。
（M1/M2 训出后复测；按类校准在 v0.2.0。）

## RQ2 结果：合成增强的价值与边界（M1，2026-08-31；M2 待训）

M1 = 与 M0 完全同配置（同起点 COCO 权重、同轮数、同 seed），唯一变量是训练数据混入
3,436 张合成损坏副本（30%）。**clean_day mAP50-95 = 0.302（M0 0.302，零牺牲）**；
随堂测验 0.316（M0 0.311，不降反升）。

| 条件 | M0 掉分 | M1 掉分 | mAP 变化 | 判读 |
| --- | ---: | ---: | ---: | --- |
| 高斯噪声（合成） | −34.3% | −15.1% | **+0.058** | 同类损坏，特效药 |
| 合成雨 | −27.7% | −13.0% | **+0.044** | 同类损坏，特效药 |
| 运动模糊（合成） | −26.6% | −21.4% | +0.016 | 有效 |
| 低光（合成） | −11.3% | −8.5% | +0.009 | 有效 |
| 雨（自然） | −9.0% | −7.1% | +0.006 | 部分迁移（雨丝特征相近） |
| **夜间（自然）** | −26.2% | −27.0% | **−0.003** | **不迁移** |
| 自然雾（9 张） | −15.2% | −19.0% | −0.012 | 样本太小不下结论 |

**两个发现**：

1. **合成增强是"对称解药"**：对训练时见过的同类合成损坏效果巨大（噪声恢复 19.2 个
   百分点），对特征相近的自然雨有部分迁移；最脆弱的 motor 类受益最大（平均掉分
   −36.0% → −25.9%）；clean 零牺牲——增强-损坏相似性假设（NeurIPS 2021）在驾驶
   数据上得到干净验证；
2. **但合成增强迁移不到真实夜间**（−26.2% → −27.0%）：真实夜是另一套光照体制
   （路灯/车灯/异质噪声统计），不是"调暗的白天"。→ 这正是 M2 存在的科学理由：
   RQ2b 要回答的就是**真实数据能不能补上合成增强补不了的那块**。

M1 校准：T = 0.770，NLL 0.3769 → 0.3673，全条件 ECE −10.7~30.4%（格局与 M0 一致，
恶劣条件受益更大：雨 −28.9%、雪 −27.0%）。

## 局限

单一数据集；单一检测器家族；自然雾仅 9 张（结论主要依赖合成雾）；v0.1.0 仅全局温度缩放；
M2 未做"仅真实数据无合成"对照（合成/真实贡献的完全分解留 v0.2.0）。
