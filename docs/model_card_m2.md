# Model Card: M2（RobustVision 旗舰检测器）

## 基本信息

| 项 | 内容 |
| --- | --- |
| 架构 | YOLO11m（Ultralytics，COCO 预训练迁移微调） |
| 任务 | 2D 目标检测（驾驶场景） |
| 类别（10） | person, rider, car, truck, bus, train, motor, bike, traffic light, traffic sign |
| 输入 | 1280×720 RGB（训练/评测分辨率 imgsz=640） |
| 训练硬件 | 单张 RTX 4060 Laptop（8GB），30 轮 × 6.47 小时 |
| 训练数据 | BDD100K train 子集（见下） |
| 随机种子 | 42（全部数据抽样与训练） |

## 训练数据构成（19,463 张/轮）

| 成分 | 数量 | 来源与筛选 |
| --- | ---: | --- |
| 晴天∩白天原图 | 11,454 | BDD100K train，weather=clear ∧ timeofday=daytime 的**全部**（实测交集仅 12,454，留 1,000 做监控后全量使用） |
| 合成损坏副本 | 4,009 | 上表原图的随机子集做 7 种像素级损坏（低光/运动模糊/高斯噪声/雾/雨/低清/JPEG），md5 播种可复现，标注框不变 |
| **真实夜间/雨天** | 4,000 | BDD100K train，timeofday=night 抽 3,000 + weather=rainy 抽 1,000（雨夜去重） |

## 各条件成绩（mAP50-95，BDD100K val test 侧）

| 条件 | M2 | 相对自身 clean |
| --- | ---: | ---: |
| 晴天白天 | 0.2961 | — |
| 夜间 | 0.2546 | −14.0% |
| 雨 | 0.2943 | −0.6% |
| 雪 | 0.2621 | −11.5% |
| 晨昏 | 0.3178 | +7.3% |
| 7 种合成损坏 | 0.2502~0.2887 | 平均 −10.2% |

对照（同配置基线 M0，仅晴天白天训练）：夜间 0.2231（−26.2%）、雨 0.2750（−9.0%）。
完整三模型阶梯表见 `results/ladder.md`。

## 置信度特性

全局温度缩放校准（T=0.808，校准集 2,999 张 clear-day）：雪/雾/雨条件 ECE 相对下降 11~20%，
**夜间 ECE 基线已良好（校准后微升 4.6%）**——模型对见过的真实条件置信度更诚实。
生产建议：若下游按置信度阈值决策，优先按条件分别标定阈值，不要全条件共用一个。

## 适用与不适用

- ✅ 适合：真实驾驶/监控场景的混合条件检测（昼夜/雨雪混合分布下综合最优，自然偏移平均比基线 +1.5 分、夜间 +3.2 分）；
- ⚠️ 权衡：纯晴天场景略逊于专用基线（−0.6 分）；对抗式合成噪声弱于纯合成增强版 M1（−0.5 分）；
- ❌ 不适合：BDD 类别之外的目标；非驾驶域（未验证）；夜间密集小目标人群仍存在系统性漏检（见 `results/qualitative_m2/`，最严重案例 17 人全部低置信度）。

## 局限

单一数据集（BDD100K，美国驾驶场景）；单一架构家族；自然雾仅 9 张测试样本（雾结论依赖合成损坏）；
未做「仅真实数据无合成」对照（合成/真实贡献的完全分解留待 v0.2.0）；温度缩放为全局单参数（按类校准在 backlog）。

## 许可

权重基于 BDD100K（研究用途许可）训练，随本项目 Release 发布，仅供研究用途；不再分发任何训练原图。
