# Model Card: M0（基线检测器）

## 基本信息

| 项 | 内容 |
| --- | --- |
| 架构 | YOLO11m（Ultralytics，COCO 预训练迁移微调） |
| 任务 | 2D 目标检测（驾驶场景，10 类同 M2） |
| 训练数据 | BDD100K「晴天∩白天」11,454 张（**仅此一类条件**） |
| 训练 | 单张 RTX 4060 Laptop（8GB），40 轮；batch 8 / seed 42 / imgsz 640（与 M1/M2 完全一致） |
| 角色 | 阶梯第 1 级：量出分布偏移的伤害，是 M1/M2 的对照基线 |

## 各条件成绩（mAP50-95，test 侧）

| 条件 | M0 | 相对自身 clean |
| --- | ---: | ---: |
| 晴天白天 | 0.3022 | — |
| 夜间 | 0.2231 | −26.2% |
| 高斯噪声 s2（最狠） | 0.1986 | −34.3% |
| 自然偏移平均（夜/雨/雪/晨昏） | 0.2668 | — |

掉分最狠的类：motor（各条件平均 −36.0%）。完整 13 条件表见 `results/ladder.md`。

## 置信度特性

温度缩放 T = 0.7624（<1：校准前**不够自信**，与文献常报告的过自信相反）；
校准集 NLL 0.3754 → 0.3650，全条件 ECE 相对下降 12~29%。

## 适用与不适用

- ✅ 适合：作为"只用理想条件数据训练会多脆弱"的实证基线，或晴天白天专用场景（clean 0.3022 为三模型最高之一）；
- ❌ 不适合：任何夜间/损坏条件下的实际部署（夜间 −26.2%、噪声 −34.3%）。

## 局限

与 M2 共享：单数据集、单架构家族。本卡数字与 `results/m0_full.md` 同源（labels10 口径）。

## 许可

权重基于 BDD100K（研究用途许可）训练，随本项目 Release 发布，仅供研究用途；不再分发任何训练原图。
